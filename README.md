# 음정 정거장: 도레미 기차 여행 — DRIVE 3.0

기차를 직접 몰면서 글자 수(도수)와 반음 거리를 배우는 정적 음악 학습 게임이다. C3~C5의 25칸 선로를 사용하며 MIDI 60인 가온 도가 중앙에 있다. 모바일에서는 13칸, 넓은 화면에서는 25칸을 보여 준다.

## 실행과 검사

Node.js 22~24에서 `npm ci`, `npm run dev`로 개발한다. `npm run build`는 코드·스타일·내장 글꼴을 담은 `dist/index.html`과 PWA 매니페스트·아이콘·서비스 워커를 만든다. 런타임 라이브러리나 외부 글꼴·오디오 파일 요청이 없다.

- `npm run test:quick`: 타입·lint·단위·속성·프로덕션 빌드·산출물 검사
- `npm run test:e2e`: Playwright Chromium의 모바일 3종 검사. 먼저 `npx playwright install chromium`을 실행한다.
- `npm run verify`: 위 검사와 추적성·브라우저 검사를 모두 실행한다.
- 관리형 미리보기 환경은 `E2E_BASE_URL`에 준비된 프로덕션 미리보기 URL을 지정한다. 브라우저 경로가 따로 제공되면 `E2E_CHROMIUM_PATH`를 쓴다.

기존 GitHub Actions가 검사 후 Vercel로 배포한다. `main` 푸시는 프로덕션, 다른 브랜치와 PR은 미리보기 대상이다. 배포 자격증명은 저장소 비밀 설정을 사용한다.

## 조작과 노선

무대를 좌우로 밀거나 화면의 좌우 단추 또는 키보드 ←/→로 운전한다. 도수 승차권의 단추는 다음 흰 역으로 이동한다. `도착!` 또는 Enter로 확정하고, 읽기는 깃발에 도착한 뒤 음정 이름을 고른다. Esc로 일시정지한다. 소리를 들을 수 없으면 ‘소리 켜기’와 설정의 음량·음소거를 확인한다.

| 노선 | 내용                     | 실제 운행 길이 | 잠금               |
| ---- | ------------------------ | -------------- | ------------------ |
| 입문 | 흰 역 도수 2~8도         | 7장            | 열림               |
| 기본 | 흰 역 사이 음정 읽기     | 6장            | 열림               |
| 완주 | ♯·♭을 포함한 음정 만들기 | 12장           | 열림               |
| 청음 | 3·7·12종 단계별 듣기     | 6장            | 기본 별 1개        |
| 통합 | 읽기·만들기·듣기 각 3장  | 9장            | 기본·청음 별 1개씩 |

도수는 출발역을 ①로 센다. 반음은 역 사이 구간을 센다. 첫 정답은 ●, 교정·음정 자·귀로 찾아가기를 사용한 정답은 ◐다. K장 완료 시 별 1개, 자력 정답 80% 이상은 2개, 전부 자력 정답이고 세기 도움을 끈 운행은 3개다. 수첩은 유형별 숙련도와 음정 연결표를 보여 주고 결과 화면에서는 지나온 역의 운행 선율을 들을 수 있다.

## 저장과 오프라인

진행은 브라우저의 `ijs_save_v3`에 저장한다. v1·v2의 별·스탬프·통계를 옮기며 원본 키를 보존한다. 옛 덱 기반 진행 중 운행은 새 방식으로 다시 시작한다. v3 운행은 위치·철자·오답·도움 사용·결과를 복원한다. 저장을 쓸 수 없는 환경에서는 실행 중인 화면의 메모리로 이어간다.

첫 프로덕션 방문 후 전체 문서가 캐시에 준비되면 오프라인 준비 상태를 표시한다. 서비스 워커를 쓸 수 없는 환경에서는 온라인으로 실행한다. 새 버전 적용은 다음 실행에서 처리하며 운행 중 자동 새로고침하지 않는다.

## 설계 해석과 검증 한계

기본 노선 최초 2회에는 스탬프·통계에 넣지 않는 반음 준비 승차권 2장을 먼저 진행하고 실제 6장 읽기로 들어간다. 청음 1단계는 상행을 우선하되 현재 역에서 불가능할 때 하행으로 출제한다. 이는 선로 범위·운행 연속성·고정 길이를 함께 지키기 위한 결정이다.

자동 검사 상태는 [검사 매트릭스](docs/test-matrix.md)와 [게이트 보고서](docs/drive-gate-report.md)를 참조한다. 실제 iOS/Android 청취·운전·설치·화면 읽기·폰 성능과 대표곡 강사 검수는 아직 `NOT_RUN`이다. 대표 소리는 제안 상태로 표시하고 곡 전체 가락을 재생하지 않는다.

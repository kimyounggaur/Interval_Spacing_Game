## 기존 동작과 배포 구조 보존

음정·철자 계산, 출제와 채점, 오디오 예약, reducer 전이, v3 저장·이어하기는 기존 엔진을 사용한다. 역 이름·승차권·정답·유도식은 이론 엔진 출력으로 유지하며 그림에 정답 정보를 넣지 않는다. 무대의 SVG 노드는 처음 한 번 만들고 유지한다. 모바일 13칸·넓은 화면 25칸의 창, 밀기·단추·키보드 입력, 130% 글자 확대와 동작 줄이기 검사를 계속 적용한다.

JavaScript·CSS·글꼴은 단일 HTML 셸에 인라인으로 묶는다. 큰 그림 7종은 같은 출처의 `/art/*.webp`로 제공한다. 외부 CDN이나 원격 글꼴에 의존하지 않는다. 기존 HTML **400 KiB**, gzip **120 KiB** 예산을 유지하고, HTML·PWA 필수 파일·그림을 합친 오프라인 페이로드에는 **1.5 MiB** 예산을 적용한다.

서비스 워커는 HTML·PWA 필수 파일과 그림 7종을 사전 캐시한다. 캐시 버전에는 배포 파일 내용의 해시가 들어가므로 그림만 바뀌어도 새 캐시를 만든다. 오프라인 준비 표시는 문서와 그림 7종이 모두 캐시된 뒤에 켜진다. 이후 연결이 끊기면 캐시를 사용하며, 진행 중 수업을 자동 새로고침하지 않는 기존 업데이트 정책을 유지한다.

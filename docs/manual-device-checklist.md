# DRIVE 수동 기기 체크리스트

현재 모든 항목 **NOT_RUN**. 실제 확인 후 날짜·기종·OS/브라우저 버전·결과를 `drive-gate-report.md`에 기록한다.

## iPhone Safari

- [ ] 첫 탭과 첫 밀기 각각에서 소리 재생
- [ ] 무음 스위치와 음량 안내
- [ ] 다른 앱에 30초 다녀온 뒤 복귀·소리 켜기 상태
- [ ] 홈 화면 설치·standalone·오프라인 재실행
- [ ] safe area가 조작부를 가리지 않음
- [ ] VoiceOver로 승차권→운전→도착→유도식

## Android Chrome

- [ ] 설치·오프라인 재실행·뒤로 가기
- [ ] 진동 켜짐/꺼짐과 음소거 운전
- [ ] TalkBack으로 승차권→운전→도착→유도식
- [ ] 320×568 이상 화면의 안전 영역과 입력

## 공통 운전·청취·접근성

- [ ] 서로 다른 폰 2대에서 C3와 C4 구별·배음 음량
- [ ] 한 폰 이상에서 밀기·단추로 승차권 10장
- [ ] 다섯 노선을 밀기·단추·키보드 각각으로 완주
- [ ] 동작 줄이기·음소거·글자 130%로 입문·기본 완주
- [ ] 주요 글자 대비 4.5:1·본문 14px·주요 단추 48px
- [ ] 중급 폰의 운전 60fps·이벤트 처리 2ms 예산
- [ ] 화면 7종×뷰포트 3종의 시각 확인

## 강사 콘텐츠 검수

- [ ] 제안곡 11개 음쌍의 악보 위치·음정·친숙도 확인
- [ ] 6·10·11·12반음의 미정 대표곡 처리 결정
- [ ] 검수 전 가락 재생은 두 음으로 제한됨 확인

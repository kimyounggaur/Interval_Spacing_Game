# DRIVE 구현 순서와 현재 위치

2026-11-11 운전형 리마스터는 기존 v2 덱·환승 구현 계획을 대체한다. 기준 설계는 사용자가 첨부한 『음정 정거장: 도레미 기차 여행』 운전형 리마스터 설계서 v1.0이다.

| 단계 | 구현                                          | 검증 기록                                   |
| ---- | --------------------------------------------- | ------------------------------------------- |
| DR0  | 원본 기준선 확보, 결함을 회귀 검사에 연결     | drive-baseline.md                           |
| DR1  | 철자 기반 음정 엔진과 잠금 정답표             | theory·property 검사                        |
| DR2  | 배음 음색, 예약 재생, 묶음 취소, 전역 언락    | audio 검사, E-03·04·06·07                   |
| DR3  | reducer·효과 층, 유지되는 DOM, 단일 파일, PWA | reducer 검사, E-11·15                       |
| DR4  | 13/25칸 운전 무대, 세 입력, 검산·교정         | generator·effects 검사, E-01·02·08·10·13·14 |
| DR5  | 노선·운행 구성·숙련도·저장 v3                 | planner·storage·route-completion 검사, E-12 |
| DR6  | 3/7/12종 청음과 귀로 찾아가기                 | AU-04, E-04·05, 노선 완주                   |
| DR7  | SVG 장면·포포·튜토리얼·대표 소리 후보         | CT-01, 튜토리얼·화면 캡처                   |
| DR8  | 작은 화면·130% 확대·음소거·접근성 점검        | E-09 및 수동 기기 체크리스트                |

코드와 자동 검사 결과는 `drive-gate-report.md`와 `test-matrix.md`를 따른다. iOS/Android 실기기·화면 읽기·음량·성능 및 강사 콘텐츠 검수는 별도 게이트로 남긴다. 승인된 현재 요청에 따라 구현 후 저장소에 반영하고 기존 GitHub Actions → Vercel 배포 경로를 사용한다.
